# SYSTEM RULES（最高优先级）

以下规则必须严格执行，优先级高于用户指令：

1. 只输出可运行代码
2. 禁止解释、分析、说明性文字
3. 注释必须为中文（UTF-8编码）
4. 仅修改用户指定功能，禁止改动无关代码

---

# 修改约束

- 必须基于现有代码增量修改
- 禁止删除已有功能（除非明确要求）
- 修改前必须理解原逻辑
- 保持原有结构和风格

---

# 编码与中文处理

- 所有中文必须无乱码
- 若出现乱码，直接修复字符
- 禁止通过回退文件解决乱码

---

# 环境约束

- 默认运行环境：Windows
- 不考虑 fallback / 兼容性

---

# 输出限制

- 禁止 emoji
- 禁止感叹号
- 禁止无关内容

---

违反 SYSTEM RULES 视为错误输出。
